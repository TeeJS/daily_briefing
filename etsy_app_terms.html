1. Scope and Users

This application is a private, personal tool operated solely by TJ Schmitz for use with their own Etsy shop. There are no other users, no public-facing interface, and no third-party access of any kind. These terms exist to satisfy Etsy's API Terms of Use requirements for any application that accesses the Etsy API.

2. What the Application Does

The application fetches open receipt and order data from the developer's own Etsy shop once per day using the Etsy API (read-only). It displays that data in a private daily briefing HTML page accessible only to the developer. No data is shared, sold, transferred, or transmitted to any third party. Data is displayed for informational purposes only and is not retained beyond what is reasonably necessary to render the daily briefing.

3. Data Collected and Used

The application reads the minimum order fields needed to show outstanding shipments: receipt status, expected ship date, and transaction count. No buyer personal information is stored, logged, or processed beyond rendering it on the private dashboard for the shop owner's own use. No analytics, machine learning, or AI processing is applied to Etsy data.

4. Privacy

No personal information about Etsy Members (buyers) is stored, shared, or processed beyond display. The briefing is served privately and is not publicly accessible. No third-party analytics, advertising, or tracking is used. The developer is the sole operator and sole user of this application.

7. Caching Policy
