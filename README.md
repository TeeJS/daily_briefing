# daily_briefing

A scheduled action that delivers a daily briefing summarizing the things I want to start each day with.

## Planned contents of the briefing

- **Important emails** — unread / high-priority threads from Gmail that need attention.
- **Daily schedule** — today's calendar events and notable upcoming items.
- **Claude account usage** — recent usage and remaining quota for my Claude / Anthropic account.
- **Notable news events** — a short digest of news worth knowing about.

## Status

Early scaffold — no automation wired up yet. The scheduled job, data sources, and delivery channel will be added in follow-up commits.
